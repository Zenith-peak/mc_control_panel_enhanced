# Minecraft 服务器控制面板

## 概述

一个功能完善的 Minecraft 服务器图形化管理工具，使用 Python 的 tkinter 库开发。它提供了服务器启动/停止、玩家管理、性能监控、世界备份等全面的服务器管理功能。

## 功能特性

### 1. 服务器控制

- **启动/停止/重启服务器**：一键控制服务器运行状态
- **UTF-8 编码支持**：完美支持中文显示
- **自动检测 IP**：自动检测本地和公网 IP 地址
- **二维码生成**：生成服务器连接二维码，方便手机端连接

### 2. 玩家管理

- **在线玩家监控**：实时显示在线玩家列表、位置、延迟
- **玩家聊天**：与在线玩家进行私聊
- **踢出玩家**：将违规玩家踢出服务器
- **传送玩家**：将玩家传送到指定位置
- **设为管理员**：快速授予玩家管理员权限

### 3. 管理员面板

- **封禁管理**：
  - 永久封禁
  - 临时封禁（支持自定义时长）
  - 自动解封（临时封禁到期自动解除）
  - 封禁列表管理
- **禁言管理**：
  - 永久禁言
  - 临时禁言
  - 自动解禁
  - 禁言列表管理
- **管理员管理**：
  - 添加/移除管理员
  - 管理员列表查看

### 4. 白名单管理

- 添加/移除白名单玩家
- 启用/禁用白名单
- 重载白名单
- 导出白名单

### 5. 世界管理

- **备份功能**：
  - 创建世界备份
  - 恢复备份
  - 自动备份设置
- **游戏规则设置**：
  - 保持物品栏
  - 生物破坏
  - 昼夜循环
  - 天气循环
  - 火焰蔓延
  - 自然生命恢复
  - 命令方块输出
- **世界设置**：
  - 设置出生点
  - 更改游戏模式
  - 更改难度
  - 设置时间

### 6. 服务器配置

- **服务器属性管理**：
  - 服务器端口
  - 在线模式
  - 最大玩家数
  - 视图距离
  - PVP 设置
  - 难度设置
  - 游戏模式
  - 生成设置（怪物、动物、NPC）
  - 允许飞行
  - 资源包
  - MOTD

### 7. 性能监控

- **系统信息**：
  - 操作系统信息
  - CPU 信息
- **实时性能指标**：
  - CPU 使用率
  - 内存使用率
  - 磁盘使用率
  - 网络上传/下载
- **服务器进程监控**：
  - 服务器 CPU 使用率
  - 服务器内存使用
- **性能历史**：记录并显示性能历史数据

### 8. 日志管理

- 实时显示服务器日志
- 清空日志
- 导出日志
- 日志搜索

### 9. 设置

- **路径设置**：
  - 服务器 JAR 文件路径
  - 服务器目录
- **Java 设置**：
  - Java 路径
  - 最小/最大内存分配
- **其他设置**：
  - 启动时自动启动服务器
  - 定期自动备份世界
  - 自动检查服务器更新

### 10. 命令自动补全

- 支持 Minecraft 命令自动补全
- 命令提示和说明
- Tab 键快速补全

## 依赖库

### 必需依赖

```bash
pip install psutil
pip install qrcode[pil]
```

### 可选依赖

- `psutil`：用于性能监控（不安装则禁用性能监控功能）
- `qrcode` 和 `PIL`：用于生成二维码（不安装则禁用二维码功能）

## 使用方法

### 1. 基本使用

```bash
python mc_control_panel_enhanced.py
```

### 2. 首次配置

1. 在"设置"标签页中配置服务器路径
2. 设置 Java 路径和内存参数
3. 保存设置

### 3. 启动服务器

1. 在"仪表板"标签页中点击"启动服务器"
2. 服务器启动后，可以在日志区域查看输出

### 4. 管理玩家

1. 在"仪表板"或"管理员面板"中管理玩家
2. 可以封禁、禁言、踢出玩家
3. 查看在线玩家列表和聊天记录

## 配置文件

配置文件保存在 `mc_panel_config.ini`，包含以下设置：

```ini
[PATHS]
jar_path = server.jar
server_dir = /path/to/server
java_path = java

[JAVA]
min_memory = 1G
max_memory = 2G

[SETTINGS]
auto_start = False
auto_backup = False
auto_update = False

[SERVER_ADDRESS]
server_ip = 192.168.1.100
server_port = 25565
```

## 命令支持

### 内置命令数据

面板内置了常用的 Minecraft 命令数据，包括：

- help, list, gamemode, give, tp, teleport
- time, weather, op, deop, ban, tempban
- pardon, kick, stop, save-all, whitelist
- say, tell, msg, seed, effect, spawnpoint
- setworldspawn, gamerule, clear, xp, defaultgamemode
- reload, mute, unmute

### 自定义命令

可以通过创建 `mc_commands.json` 文件来扩展命令数据：

```json
{
  "commands": {
    "customcommand": {
      "description": "自定义命令描述",
      "usage": "/customcommand <参数>",
      "permission": 2,
      "suggestions": ["选项1", "选项2"]
    }
  }
}
```

## 注意事项

1. **Java 环境**：确保已安装 Java 并正确配置路径
2. **服务器 JAR**：确保服务器 JAR 文件存在且可访问
3. **权限**：某些功能可能需要管理员权限
4. **防火墙**：确保防火墙允许 Minecraft 服务器端口
5. **备份**：定期备份世界数据，防止数据丢失

## 故障排除

### 中文显示乱码

- 确保使用 UTF-8 编码
- 检查 Java 环境编码设置

### 无法启动服务器

- 检查 Java 路径是否正确
- 检查服务器 JAR 文件是否存在
- 检查内存设置是否合理

### 性能监控不工作

- 安装 psutil 库：`pip install psutil`

### 二维码功能不工作

- 安装 qrcode 和 PIL：`pip install qrcode[pil]`

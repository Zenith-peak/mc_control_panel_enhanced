## 1. 系统概述

### 1.1 产品定位

Minecraft 服务器控制面板是一款面向 Minecraft 服务器管理员的专业管理工具，提供图形化界面来简化服务器运维工作。

### 1.2 目标用户

- Minecraft 服务器所有者（服主）
- 服务器管理员（OP）
- 服务器技术支持人员

### 1.3 技术栈

- **前端框架**: Tkinter (Python GUI)
- **后端语言**: Python 3.8+
- **依赖库**: psutil, qrcode, PIL

## 2. 核心功能模块

### 2.1 仪表板模块

#### 2.1.1 功能名称

仪表板 (Dashboard)

#### 2.1.2 功能目的

提供服务器状态的实时监控和快速操作入口，是管理员日常管理的核心界面。

#### 2.1.3 核心功能点

**A. 服务器状态监控**

- **功能描述**: 实时显示服务器运行状态
- **监控指标**:
  - 服务器运行状态（运行中/已停止）
  - 在线玩家数量（当前/最大）
  - 服务器版本信息
  - 内存使用情况（已用/总量）
  - CPU使用率（需要psutil）
- **数据刷新频率**: 5秒自动刷新
- **输入**: 无
- **输出**: 可视化状态面板

**B. 服务器控制**

- **启动服务器**
  - 触发条件: 点击"启动服务器"按钮
  - 处理流程:
    1. 检查Java环境
    2. 验证server.jar存在
    3. 启动服务器进程
    4. 更新状态显示
  - 输出: 服务器进程ID
  - 异常处理: Java未安装、内存不足、端口占用
- **停止服务器**
  - 触发条件: 点击"停止服务器"按钮
  - 处理流程:
    1. 发送stop命令
    2. 等待服务器关闭（超时30秒）
    3. 强制终止（如需要）
  - 输出: 停止结果状态
  - 异常处理: 服务器无响应、保存失败
- **重启服务器**
  - 触发条件: 点击"重启服务器"按钮
  - 处理流程: 先执行停止，再执行启动
  - 边界条件: 服务器未运行时不执行

**C. 快速命令执行**

- **功能描述**: 提供常用命令的一键执行
- **命令列表**:
  | 命令               | 功能     | 权限要求 |
  | ---------------- | ------ | ---- |
  | save-all         | 保存世界   | 等级3+ |
  | reload           | 重载配置   | 等级4  |
  | list             | 查看在线玩家 | 等级1+ |
  | stop             | 停止服务器  | 等级3+ |
  | weather clear    | 设置晴天   | 等级2+ |
  | time set day     | 设置白天   | 等级2+ |
  | whitelist on/off | 白名单开关  | 等级3+ |

**D. 服务器地址管理**

- **IP地址配置**
  - 输入: IP地址字符串
  - 验证: IPv4格式验证
  - 输出: 配置保存状态
- **端口配置**
  - 输入: 端口号（1-65535）
  - 默认值: 25565
  - 验证: 数字范围验证
- **自动检测功能**
  - 检测本地IP: 获取本机局域网IP
  - 检测公网IP: 通过外部服务获取
  - 输出: IP地址字符串
- **二维码生成**
  - 输入: 服务器地址+端口
  - 处理: 生成连接二维码
  - 输出: 二维码图像
  - 依赖: qrcode, PIL库

**E. 玩家聊天功能**

- **功能描述**: 以控制台身份发送消息
- **输入**: 聊天消息字符串
- **处理**: 通过RCON或控制台发送
- **输出**: 消息发送状态
- **边界条件**: 消息长度限制（100字符）

#### 2.1.4 使用场景

- 日常服务器状态检查
- 快速执行常用命令
- 服务器启停操作
- 玩家管理和沟通

#### 2.1.5 操作流程

```
1. 打开控制面板 → 自动显示仪表板
2. 查看服务器状态区域 → 了解当前运行状况
3. 使用控制按钮 → 执行启停操作
4. 点击快速命令 → 执行常用管理命令
5. 配置服务器地址 → 设置连接信息
```

#### 2.1.6 异常处理机制

| 异常类型     | 触发条件    | 处理方式    | 用户提示               |
| -------- | ------- | ------- | ------------------ |
| Java未安装  | 启动时检测失败 | 显示安装指引  | "Java未安装，请先安装Java" |
| 内存不足     | 启动时内存检测 | 建议增加内存  | "内存不足，建议分配更多内存"    |
| 端口占用     | 启动时端口检测 | 提示更换端口  | "端口被占用，请更换端口"      |
| 服务器无响应   | 停止时超时   | 强制终止进程  | "服务器无响应，已强制终止"     |
| RCON连接失败 | 发送命令时   | 使用控制台方式 | "RCON连接失败，使用控制台发送" |

#### 2.1.7 与其他模块的关联

- **管理员面板**: 共享玩家列表数据
- **性能监控**: 提供基础性能数据
- **日志查看**: 显示命令执行日志

### 2.2 管理员面板模块

#### 2.2.1 功能名称

管理员面板 (Admin Panel)

#### 2.2.2 功能目的

提供玩家管理的高级功能，包括封禁、禁言、管理员设置等操作。

#### 2.2.3 核心功能点

**A. 快捷操作工具栏**

- **功能描述**: 提供常用操作的快速入口
- **快捷封禁按钮**:
  | 按钮  | 功能    | 触发命令            |
  | --- | ----- | --------------- |
  | 1小时 | 封禁1小时 | ban <player> 1h |
  | 1天  | 封禁1天  | ban <player> 1d |
  | 7天  | 封禁7天  | ban <player> 7d |
  | 永久  | 永久封禁  | ban <player>    |
- **快捷禁言按钮**:
  | 按钮   | 功能     | 触发命令              |
  | ---- | ------ | ----------------- |
  | 30分钟 | 禁言30分钟 | mute <player> 30m |
  | 2小时  | 禁言2小时  | mute <player> 2h  |
  | 1天   | 禁言1天   | mute <player> 1d  |
- **全局搜索框**
  - 输入: 玩家名称关键字
  - 处理: 实时过滤所有列表
  - 输出: 过滤后的结果
  - 触发方式: 键盘输入时实时触发

**B. 封禁管理功能**

**封禁操作**

- **输入参数**:
  | 参数   | 类型  | 必填 | 说明      |
  | ---- | --- | -- | ------- |
  | 玩家名称 | 字符串 | 是  | 要封禁的玩家  |
  | 封禁类型 | 枚举  | 是  | 临时/永久   |
  | 封禁时间 | 字符串 | 条件 | 临时封禁时必填 |
  | 封禁原因 | 字符串 | 否  | 封禁理由    |
- **时间格式**:
  - 分钟: m (如: 30m)
  - 小时: h (如: 2h)
  - 天数: d (如: 7d)
- **处理流程**:
  1. 验证玩家名称有效性
  2. 检查玩家是否已被封禁
  3. 计算解封时间（临时封禁）
  4. 执行封禁命令
  5. 更新封禁列表
  6. 记录操作日志
- **输出**: 封禁成功/失败状态
- **边界条件**:
  - 玩家名称不能为空
  - 临时封禁必须设置时间
  - 不能重复封禁同一玩家

**封禁列表**

- **显示字段**:
  | 字段   | 说明      | 数据来源                |
  | ---- | ------- | ------------------- |
  | 玩家   | 被封禁玩家名称 | banned-players.json |
  | 原因   | 封禁原因    | 用户输入                |
  | 类型   | 临时/永久   | 用户选择                |
  | 剩余时间 | 临时封禁倒计时 | 自动计算                |
  | 状态   | 封禁中/已过期 | 自动判断                |
- **列表操作**:
  - 单击选中
  - Ctrl+单击多选
  - 右键菜单操作

**批量操作**

- **批量解封**
  - 输入: 选中的玩家列表
  - 处理: 逐个执行解封命令
  - 输出: 批量操作结果
  - 确认: 操作前需确认
- **批量更新**
  - 功能: 批量修改封禁信息
  - 可更新字段: 封禁时间、原因

**C. 禁言管理功能**

**禁言操作**

- **输入参数**:
  | 参数   | 类型  | 必填 | 说明      |
  | ---- | --- | -- | ------- |
  | 玩家名称 | 字符串 | 是  | 要禁言的玩家  |
  | 禁言类型 | 枚举  | 是  | 临时/永久   |
  | 禁言时间 | 字符串 | 条件 | 临时禁言时必填 |
  | 禁言原因 | 字符串 | 否  | 禁言理由    |
- **处理流程**: 同封禁操作
- **输出**: 禁言成功/失败状态

**禁言列表**

- **显示字段**: 同封禁列表
- **数据来源**: muted-players.json

**D. 管理员管理功能**

**管理员权限等级**

- **等级1 - 基础管理员**:
  - 命令权限: /kick, /ban, /pardon, /ban-ip, /pardon-ip, /op, /deop
  - 功能范围: 玩家基础管理
  - 适用角色: 普通管理员
- **等级2 - 中级管理员**:
  - 包含等级1权限
  - 额外权限: /gamemode, /difficulty, /weather, /time, /tp, /give, /effect, /clear
  - 功能范围: 游戏环境管理
  - 适用角色: 高级管理员
- **等级3 - 高级管理员**:
  - 包含等级1-2权限
  - 额外权限: /stop, /save-all, /save-off, /save-on, /whitelist, /seed, /publish
  - 功能范围: 服务器运行管理
  - 适用角色: 技术管理员
- **等级4 - 完全权限**:
  - 包含等级1-3权限
  - 额外权限: /reload, /defaultgamemode, /setworldspawn, /worldborder, /scoreboard, /datapack, /advancement
  - 功能范围: 完全控制
  - 适用角色: 服主

**添加管理员**

- **输入参数**:
  | 参数   | 类型  | 必填 | 说明        |
  | ---- | --- | -- | --------- |
  | 玩家名称 | 字符串 | 是  | 要设为管理员的玩家 |
  | 权限等级 | 整数  | 是  | 1-4       |
- **处理流程**:
  1. 验证玩家名称
  2. 检查是否已是管理员
  3. 执行/op命令
  4. 记录到ops.json
  5. 更新管理员列表

**移除管理员**

- **输入**: 选中的管理员
- **处理**: 执行/deop命令
- **输出**: 操作结果

**管理员列表**

- **显示字段**:
  | 字段   | 说明       |
  | ---- | -------- |
  | 玩家   | 管理员名称    |
  | 权限等级 | 1-4      |
  | 添加时间 | 设为管理员的时间 |
  | 状态   | 在线/离线    |

#### 2.2.4 使用场景

- 处理违规玩家（封禁/禁言）
- 管理服务器管理员团队
- 批量处理玩家操作
- 查看管理历史记录

#### 2.2.5 操作流程

```
封禁玩家:
1. 打开管理员面板
2. 在封禁管理卡片中选择玩家
3. 选择封禁类型（临时/永久）
4. 设置封禁时间（临时封禁）
5. 输入封禁原因
6. 点击"封禁玩家"按钮
7. 确认操作

设置管理员:
1. 在管理员管理卡片中选择玩家
2. 查看权限等级说明（点击帮助按钮）
3. 选择合适的权限等级
4. 点击"设为管理员"
5. 确认操作
```

#### 2.2.6 异常处理机制

| 异常类型   | 触发条件    | 处理方式   | 用户提示                 |
| ------ | ------- | ------ | -------------------- |
| 玩家不存在  | 封禁/禁言时  | 检查玩家列表 | "玩家不存在或不在线"          |
| 重复封禁   | 玩家已被封禁  | 拒绝操作   | "该玩家已被封禁"            |
| 权限不足   | 当前用户等级低 | 拒绝操作   | "您的权限等级不足"           |
| 无效时间格式 | 时间格式错误  | 格式校验   | "时间格式无效，请使用如：1h, 2d" |
| 文件读写失败 | 保存数据时   | 重试机制   | "保存失败，请重试"           |

#### 2.2.7 与其他模块的关联

- **仪表板**: 共享玩家在线状态
- **玩家管理**: 共享玩家数据
- **日志查看**: 记录管理操作日志

### 2.3 玩家管理模块

#### 2.3.1 功能名称

玩家管理 (Player Management)

#### 2.3.2 功能目的

管理服务器玩家数据，包括白名单、玩家信息查看等。

#### 2.3.3 核心功能点

**A. 白名单管理**

- **添加白名单**
  - 输入: 玩家名称
  - 命令: /whitelist add <player>
  - 输出: 添加结果
- **移除白名单**
  - 输入: 选中的玩家
  - 命令: /whitelist remove <player>
  - 输出: 移除结果
- **白名单列表**
  - 显示: 所有白名单玩家
  - 数据来源: whitelist.json
- **白名单开关**
  - 功能: 开启/关闭白名单验证
  - 命令: /whitelist on/off

**B. 玩家数据管理**

- **查看玩家数据**
  - 显示信息:
    - 玩家名称
    - UUID
    - 首次登录时间
    - 最后登录时间
    - 游戏时长
    - 成就统计
- **重置玩家数据**
  - 功能: 重置玩家存档
  - 确认: 需要二次确认
  - 警告: 数据不可恢复

#### 2.3.4 使用场景

- 管理服务器访问权限
- 查看玩家活动记录
- 处理玩家数据问题

### 2.4 世界管理模块

#### 2.4.1 功能名称

世界管理 (World Management)

#### 2.4.2 功能目的

管理Minecraft世界数据，包括备份、恢复、重置等操作。

#### 2.4.3 核心功能点

**A. 世界备份**

- **手动备份**
  - 触发: 点击"备份世界"按钮
  - 处理流程:
    1. 检查服务器状态（运行中需先保存）
    2. 创建备份目录（按时间命名）
    3. 复制世界文件夹
    4. 生成备份信息文件
  - 输出: 备份路径
  - 边界条件: 磁盘空间检查
- **自动备份**
  - 配置: 备份间隔、保留数量
  - 触发: 定时任务
  - 存储: 自动管理备份文件

**B. 世界恢复**

- **选择备份**
  - 输入: 从备份列表选择
  - 显示: 备份时间、大小、描述
- **恢复流程**
  1. 停止服务器（如运行中）
  2. 备份当前世界（可选）
  3. 删除当前世界
  4. 复制备份数据
  5. 验证恢复结果
  6. 启动服务器
- **确认机制**: 二次确认 + 风险提示

**C. 世界重置**

- **功能**: 删除当前世界，生成新世界
- **警告**: 数据将永久丢失
- **确认**: 需要输入确认码

**D. 多世界管理**（如安装多世界插件）

- 世界列表显示
- 世界间传送
- 世界属性配置

#### 2.4.4 异常处理

| 异常      | 处理       |
| ------- | -------- |
| 磁盘空间不足  | 提示清理空间   |
| 备份文件损坏  | 尝试其他备份   |
| 恢复失败    | 自动回滚     |
| 世界文件被占用 | 提示关闭相关程序 |

### 2.5 服务器配置模块

#### 2.5.1 功能名称

服务器配置 (Server Configuration)

#### 2.5.2 功能目的

编辑和管理server.properties配置文件。

#### 2.5.3 核心功能点

**A. 配置编辑器**

- **显示格式**: 键值对表格
- **支持类型**:
  - 字符串（服务器名称、MOTD）
  - 整数（最大玩家数、视距）
  - 布尔值（在线模式、PVP）
  - 枚举（游戏模式、难度）

**B. 常用配置项**

| 配置项           | 说明     | 默认值                |
| ------------- | ------ | ------------------ |
| server-port   | 服务器端口  | 25565              |
| max-players   | 最大玩家数  | 20                 |
| gamemode      | 默认游戏模式 | survival           |
| difficulty    | 游戏难度   | easy               |
| online-mode   | 正版验证   | true               |
| white-list    | 白名单    | false              |
| pvp           | PVP开关  | true               |
| view-distance | 视距     | 10                 |
| motd          | 服务器描述  | A Minecraft Server |

**C. 配置验证**

- 端口范围验证（1-65535）
- 数值范围验证
- 枚举值验证

**D. 配置保存**

- 自动备份原配置
- 写入新配置
- 提示重启生效

### 2.6 插件管理模块

#### 2.6.1 功能名称

插件管理 (Plugin Management)

#### 2.6.2 功能目的

管理服务器插件（适用于Bukkit/Spigot/Paper服务器）。

#### 2.6.3 核心功能点

**A. 插件列表**

## 4. 异常处理机制

### 4.1 异常分类

| 级别 | 类型   | 示例         | 处理方式           |
| -- | ---- | ---------- | -------------- |
| 严重 | 系统错误 | 内存不足、磁盘已满  | 提示用户，记录日志，优雅退出 |
| 中等 | 业务错误 | 玩家不存在、权限不足 | 提示用户，记录日志，继续运行 |
| 轻微 | 输入错误 | 格式错误、范围超限  | 即时提示，要求重新输入    |
| 信息 | 状态提示 | 操作成功、数据刷新  | 状态栏显示，可选提示     |

### 4.2 错误码定义

| 错误码  | 说明       | 解决方案         |
| ---- | -------- | ------------ |
| E001 | Java未安装  | 安装Java环境     |
| E002 | 服务器文件不存在 | 检查server.jar |
| E003 | 端口被占用    | 更换端口或关闭占用程序  |
| E004 | 权限不足     | 以管理员身份运行     |
| E005 | 配置文件损坏   | 恢复默认配置       |
| E006 | 备份失败     | 检查磁盘空间       |
| E007 | 网络连接失败   | 检查网络设置       |
| E008 | RCON连接失败 | 检查RCON配置     |

### 4.3 日志记录

- **日志级别**: DEBUG, INFO, WARNING, ERROR, CRITICAL
- **日志格式**: \[时间] \[级别] \[模块] 消息
- **日志文件**: logs/server\_log\_YYYYMMDD\_HHMMSS.txt
- **日志轮转**: 按天分割，保留30天
